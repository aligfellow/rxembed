**Companion to `seed-vs-relax.md`.** Measurement only — no code was changed by this study. Date
2026-07-20, branch `rdkit-embed-kernel` at `4dee01b`.

> **Tree provenance.** A concurrent agent wrote `src/rxembed/pipeline.py` (20:15) and
> `src/rxembed/metrics.py` (20:16) **during** the main run (20:11–20:41), so part of the corpus was
> measured before those writes and part after. AGENTS.md warns that exactly this has produced a spurious
> result here before, so the whole corpus was **re-run against the current tree** and every metric
> diffed: **bit-for-bit identical on all 81 case-seed rows** (27 cases × seeds 1, 2, 3 — seed scores,
> relax scores and drift all exact matches).
>
> ```bash
> uv run python $S/o3_seed_vs_relax_organic.py o3_recheck.json 1 2 3   # then diff vs o3_main.json
> ```
>
> The writes are the change under test plus a `bonding_ok(constrained=)` exemption; neither alters any
> coordinate or score measured here. `o4`, `o6`, `o7` and `o8` all ran entirely after 20:41, against the
> settled tree.

**The concern being tested.** `rx.embed()` now relaxes its ETKDG seeds into their constraint windows at
the pipeline's single return point (`pipeline._relax_embedded` → `Ensemble._relax_into_windows`). The
metal study cleared that change on transition-metal complexes and explicitly did *not* clear organics
(`seed-vs-relax.md` §9, "Organic systems generally"). Two contradictory pieces of evidence were on record:
the relax **breaks thiourea conjugation** on `bimp` — the organocatalysis motif this package targets — and
the relax **fixes** conjugation the seed had broken on other organocatalysis SMILES.

**Verdict in one line.** The thiourea claim is **REPRODUCED exactly** — and the framing around it is
**REFUTED**. The twist is real: `geometry.check` on `embed()`'s own output falls **44.6% → 30.3%** (1054
conformer pairs, 5 seeds), 211 conformers clean→FAIL against 60 FAIL→clean, and the harm is one localised
force-field defect (**534 of 864 thiourea `S=C-N` quartets** cross the 30° gate after the relax against
**10** before, while every C=O class *improves*). But the relax is **the same UFF relax `minimize` was
already going to run, moved earlier**: put the seed and the relaxed seed through the documented
`embed → minimize` chain and the two converge to **identical gate verdicts on 235/235 conformers with a
conjugation difference of 0.00°** (§6.3). The relax therefore **adds no damage to the pipeline's
product** — it surfaces pre-existing damage one stage earlier, while buying real window enforcement
(angle violation **24.8° → 0.0°**), better bond lengths (**0.0251 → 0.0192 Å**, 983/1054) and a
**0.000 Å** frozen core. **The relax stands as-is. It does not need a gate. The C=S torsion needs
narrowing — and always did.** See [Verdict](#8-verdict).

## 3. Methodology, guards, and what counts as ground truth

### One embed, two geometries

`Ensemble._relax_into_windows` is monkeypatched to snapshot every conformer's coordinates immediately
before delegating to the real method. **Both sides come from one `rx.embed()` call on the shipped code
path**, paired exactly by conformer id. There is no second embed whose seeds might differ, and the path
measured is literally the path under test. Both sides are then scored on **one** molecule (the returned
`Ensemble.mol`) driven to each coordinate set in turn, so graph, perception and hybridisation are
byte-identical across the comparison.

### Guards (`o7_guards.py`, asserted on live cases)

| # | Guard | Result |
|---|---|---|
| G0 | The snapshot is bit-identical to `embed.dispatch._embed_dispatch` called with the same arguments and seed — i.e. it really is the raw ETKDG seed, and nothing relaxes it earlier in the chain. | **ok on all 12 constrained cases checked**; `free-tetramisole` FAILs, an unconstrained stereo-enumerated case whose candidate ordering differs between the two entry points. It contributes no scored pair. |
| G1 | The relax seam fires exactly once per returned `Ensemble`. | ok, 15/15 |
| G2 | No scored "seed" is a bit-identical copy of the input geometry (the retain-input trap the metal study caught late). | ok — and see the note below |
| G3 | A second independent `rx.embed()` with the same seed reproduces the snapshot bit-for-bit. | **ALL PASS**, 27 cases × 5 seeds |
| G4 | Seed and relaxed coordinates actually differ. | **1054/1054 moved**, 0 unmoved |
| G5 | Atom count and element ordering identical pre/post, so one scoring graph is valid for both. | ok |
| G6 | An **unconstrained** embed leaves every coordinate untouched — the relax must return early. | **30/30 verified byte-identical no-op** |

G6 is worth stating plainly: on `rx.embed('CCO')` and every other free conformer search, the shipped
relax **does nothing at all**. All harm and all benefit below is confined to constrained embeds.

G2 note: unlike the metal path, none of these organic cases returned the input as conformer 0. The trap
did not fire here — but the check is in the harness, because it is a property of the code path, not of
the corpus.

### Ground truth — stated, not substituted

There is **no crystal reference for a SMILES input**, and none was invented. Three separate footings are
used and each is labelled where it appears:

1. **Real geometries** (`.xyz` cases: `bimp`, `thia-ma`, `cpa`, `spiro-ts1`, `jacob_ts4`). The shipped DFT
   geometry is scored through the same code as a third column. This is truth for bond length,
   conjugation and the gate.
2. **Absolute axes needing no reference.** Conjugation planarity is a chemistry fact — an amide /
   thiourea `C(=X)–N` is planar, which is exactly what `geometry.conjugation`'s 30° window encodes — so
   0° is right for a SMILES input too. Constraint-window satisfaction is likewise absolute: the window
   is the user's own stated target.
3. **Real-energy probe** (`o4_truth_probe.py`, GFN-FF via `xtb` 6.7.1): each conformer's seed and relaxed
   geometry is single-pointed *and* optimised, asking (i) which geometry a conjugation-aware energy
   prefers, and (ii) whether the twist survives to a real minimum.

**Bond length on a SMILES source** is reported against **MMFF94-relaxed** bond lengths for the same
molecule. That is a **force-field proxy, not truth**, and is labelled as such in the table. The `.xyz`
cases carry the real reference and agree with it.

### One thing the reference exposes about the windows

For `bimp`, the **real DFT geometry violates two of its own applied distance windows** — pairs `(43,151)`
by **8.97 Å** and `(31,117)` by **1.03 Å**. Those are the auto-added *encounter* windows for a
multi-fragment input; the six `fix`-derived core windows are satisfied to 0.00 Å by construction. So
"the relax drives window violation to zero" means *the relax satisfies the spec it was given*, and for a
multi-fragment input that spec is **not** the same thing as the real geometry. This is the organic
counterpart of the metal study's crystal-baseline caveat, and it is sharper here: on the metal path the
windows were derived from the input, so the crystal satisfied them by construction; here they are not,
and it does not.

## 6. Why — the decisive diagnostics

### 6.1 It is the C=S torsion, and nothing else

`o6_quartet_breakdown.py` classifies **every** conjugation quartet in the corpus by motif and reports the
deviation on each side (embed seeds 1, 2, 3):

| quartet class | n | seed | relax | Δ | > 30° seed | > 30° relax |
|---|---|---|---|---|---|---|
| **thiourea** `S=C-N-H`, N-aryl | 12 | 1.1° | **38.5°** | +37.4 | 0 | 7 |
| **thiourea** `S=C-N-C`, N-aryl | 444 | 5.1° | **40.4°** | +35.2 | 10 | **310** |
| **thiourea** `S=C-N-C` | 396 | 4.1° | **37.3°** | +33.3 | 0 | **215** |
| amide `O=C-N-C`, N-aryl | 36 | 4.1° | 28.0° | +23.9 | 0 | 11 |
| **thiourea** `S=C-N-H` | 12 | 1.1° | 14.7° | +13.6 | 0 | 2 |
| ester `O=C-O-C` | 48 | 0.0° | 5.1° | +5.1 | 0 | 0 |
| **carboxyl** `O=C-O-H` | 46 | 24.6° | **2.4°** | **−22.2** | 16 | **0** |
| **amide** `O=C-N-H` | 384 | 54.2° | **26.5°** | **−27.7** | 312 | **137** |

**This is the whole result in one table.** Every `C=S` class is degraded by 13–37°, and **534 of 864
thiourea quartets cross the 30° gate after the relax against 10 before**. Every `C=O` class with an
acidic/`N-H` substituent is *improved*, substantially: the relax removes **all 16** carboxyl violations
and **175 of 312** amide `N-H` violations. The one mixed case, N-aryl amide, is the smallest sample (36)
and the closest chemical neighbour of the thiourea.

**Inference (not measured):** UFF has no `S_R`–`C_R` torsion barrier comparable to the amide's, so a
thiocarbonyl `C–N` bond relaxes as if it were a single bond. The measurement establishes *that* the harm
is C=S-localised; the force-field cause is inferred from that localisation, not independently tested.

### 6.2 A real energy prefers the relaxed geometry, and mostly repairs the twist

`o4_truth_probe.py`, GFN-FF, 24 seed/relax pairs across six cases:

- **Single-point energy: the relaxed geometry is lower in *every one* of the 24 pairs.** Range −1.8 to
  −240.9 kcal/mol (`schreiner-acetone` −1.8 to −13.1; `takemoto` −19 to −23; `bimp` −101 to −206).
  **Caveat:** GFN-FF derives its topology from the geometry, so cross-geometry single points are only
  strictly comparable when the perceived topology matches; the large magnitudes on `bimp`/`cpa` should be
  read as *direction*, not size. The small, well-behaved cases carry the same sign.
- **GFN-FF optimisation: the twist is usually transient.** `schreiner-acetone` seed 0.2–0.8° → relax
  23–36° → **after optimisation 0.5–1.3° from the relaxed side and 0.7–1.1° from the seed side** — fully
  repaired, indistinguishable. `bimp`: relax 18.8–68.2° → after optimisation 10.0–20.1°, against the seed
  side's 8.8–19.3° and the real geometry's 12.8° — repaired, both sides landing on the reference. But
  **`takemoto-acetone` is a genuine counter-example**: relax 35–47° → after optimisation **50.3°, 12.3°,
  49.0°, 14.7°**, versus the seed side's 4.6–13.1°. On two of four conformers the twist **survives**
  relaxation to a real minimum and ends worse than where the seed leads.

So the damage is recoverable by a downstream real-energy `optimize()` in most cases but **not
reliably** — and it is never recoverable by anything inside `rx.embed()` itself, which is what
`geometry.check` and every notebook inspect.

### 6.3 Does the harm survive the documented chain?

The documented pipeline is `embed → (mc) → minimize`, and `minimize` runs the same restrained UFF. If the
chain converges to the same place either way, the regression is confined to the raw `embed()` output.
`o8_chain_effect.py` measures four geometries from one embed: **A** the seed, **B** what `embed` returns
today, **C** `B.minimize()`, **D** the seed put through `minimize()` with `_seeds_relaxed` cleared — i.e.
exactly the chain as it ran *before* the relax shipped.

22 cases × 3 seeds (1, 2, 3) × 4 conformers = **237 conformers**. `bimp-smiles-auto` is excluded for
runtime (32 candidates × 2 minimises), and `minimize(_retry=False)` disables `_reembed_until_clean` so no
fresh seed is substituted mid-relax.

```
A_seed        gate clean  191/237  (80.6%)   conj_max mean   8.0 deg
B_embed       gate clean  160/237  (67.5%)   conj_max mean  10.8 deg
C_embed_min   gate clean  160/237  (67.5%)   conj_max mean  10.8 deg
D_seed_min    gate clean  158/235  (67.2%)   conj_max mean  10.8 deg
```

**C and D are the same geometry.** Over the 235 conformers both paths retain:

- **gate verdict identical on 235/235** — not one conformer differs;
- **conjugation max identical to 0.00°, mean and maximum difference both 0.00°.**

The two conformers where they differ at all are `salt-bridge` seeds 2 and 3, where the **old** path (D)
*lost* a conformer to `minimize`'s energy-window filter that the new path keeps — the new path is ahead,
by two conformers, not behind.

This is not a coincidence and it is not a null measurement: `_relax_into_windows` calls
`_relax_constrained(_DISTANCE_FC)`, which is **the same function `minimize` calls**, on the same seed
under the same constraints. The change moved that relax earlier in the chain; it did not add one. (B == C
because `_relax_into_windows` sets `_seeds_relaxed`, so `minimize` single-points instead of relaxing a
second time — which is exactly the intended contract.)

### 6.4 Nothing catches it

`Ensemble._reembed_until_clean` — the mechanism that answers a torn conformer by re-embedding — is
**metal-only** (`pipeline.py`, gated on `self._metal`). `_rescue_torn`, which the embed relax does run,
tests `_metrics.bonding_ok` only: a conformer whose bonds are intact but whose thiourea is twisted 68° is
not "torn" and is kept. The docstring's claim that

> embed's output is then never worse than the seed on any conformer

is **true as scoped to bond tearing and false as written**: measured over 1054 conformers, 211 go
clean→FAIL on `geometry.check` and conjugation degrades on 492.

## 8. Verdict

**Question: does the shipped relax stand on organics as-is, does it need a gate, or does it need to be
narrowed?**

### Answer: it stands as-is. It does not need a gate. What needs narrowing is the C=S torsion — a defect that predates the relax and is not caused by it.

**The single fact that decides it (measured, §6.3).** Run the documented chain both ways — seed →
`minimize()` (the pipeline before the change) and relaxed seed → `minimize()` (the pipeline today) — and
they land on the same geometry: **235/235 identical gate verdicts, conjugation difference 0.00°**. The
relax is `_relax_constrained(_DISTANCE_FC)`, the *same call* `minimize` makes. It was moved earlier, not
added. Therefore **no measured degradation in this study is damage the relax caused to the pipeline's
output** — all of it is damage `minimize` was already doing, now visible one stage sooner. Where the two
paths differ at all, the new one is ahead (`salt-bridge`: 12/12 kept vs 10/12).

**Why it stands — measured.**

- It does what it was shipped to do. Angle-window violation **6.74° → 0.000°** per case (24.77° → 0.0001°
  per conformer, 787 help / 2 hurt); distance-window **0.0735 → 0.0032 Å**. A raw organic seed genuinely
  does not satisfy its own constraints.
- **Bond lengths improve on every single case** (MAE 0.0270 → 0.0179 Å, 23/23 cases, 983/1054
  conformers), measured against real DFT geometries on the five `.xyz` cases.
- **The frozen-core contract is untouched**: 0.0000 Å drift on both sides, all 1054 conformers.
- It **repairs** conjugation the seed had broken wherever the motif is a C=O: carboxyl `O=C-O-H` 24.6° →
  2.4° (16 violations → 0), amide `O=C-N-H` 54.2° → 26.5° (312 → 137). `acid-angle` 11/20 → 20/20,
  `acetic-pyridine` 13/20 → 20/20, `jacob_ts4` 10/20 → 20/20.
- A real GFN-FF energy prefers the relaxed geometry in **24 of 24** pairs probed.
- On free (unconstrained) embeds it is a **verified byte-identical no-op**, 30/30 — it costs nothing
  where there is nothing to enforce.

**What is nonetheless real and must be fixed — measured.**

The relax did not *create* this, but it makes it the first thing a user sees, and it is a genuine defect
in the restrained UFF relax wherever that relax runs:

- `geometry.check` on `embed()`'s own output falls **44.6% → 30.3%**, stable across five seeds
  (29.7–31.4% relaxed vs 42.8–47.1% seed). 211 clean→FAIL against 60 FAIL→clean. `embed()`'s output is
  the public API surface and the thing every notebook renders and gates, so this matters even though the
  chain's end state is unchanged.
- The harm is **localised, not diffuse**: **534 of 864 thiourea `S=C-N` quartets cross the 30° gate after
  the relax, against 10 before**, while every C=O class improves. The organocatalysis motif this package
  targets is the one it breaks.
- Against real DFT geometry, `bimp` goes seed **1.6°** → relax **42.3°** past a reference at **12.8°**.
  The relax overshoots the truth; it does not approach it.
- A downstream `optimize('gfnff')` repairs the twist in most cases but **not reliably** —
  `takemoto-acetone` ends at 50.3° and 49.0° on two of four conformers, worse than the seed route.

**Why not a gate.** An organic `_reembed_until_clean` would re-embed on gate failure. That answers a
*stochastic* failure — a bad seed among good ones. This failure is not stochastic: it is the same
force-field defect on the same torsion in every conformer of every thiourea, seed-independent to within
1.7 points across five seeds. A re-embed loop would burn the caller's `n` re-drawing seeds that all get
twisted the same way. **`bimp` at seed 2 is 0/4 — there is nothing clean to re-embed toward.** Worse, a
gate on the raw embed output would be gating an intermediate that §6.3 shows is not the product; it would
add cost and change nothing downstream.

**What narrowing means — inferred, not measured.** §6.1 localises the harm to the `C=S` torsion, which is
exactly the shape of `constraints/metal.py::_coplanar_donor` — a soft dihedral cap holding a conjugated
sp2 centre in its own π-plane, already in the codebase, already applied inside `restrained_uff`. Applying
the same cap to a thiocarbonyl `C–N` bond would fix `embed()` and `minimize()` at once, because §6.3
shows they run the same relax. **This was not tested and is a proposal, not a result.**

**The second, unnamed regression.** `planarity` violations rise **15 → 281**, driven by `cpa`
(17/20 → 0/20) and `chb-tetramisole` (40/40 → 0/40), both with conjugation flat at 0.0°. Like the
thiourea mode it is present in `minimize()` too (§6.3: `cpa` and `chb-tetramisole` are 0/12 on both C and
D). It is a *separate* defect, larger in absolute count, and **this study did not diagnose it.** It
should be its own measurement.

### What this refutes

> the embed relax degrades the organic answer

**REFUTED as a statement about the pipeline's output.** The chain converges to the same geometry either
way — 235/235 identical gate verdicts, 0.00° conjugation difference — and where it differs the new path
keeps two more conformers. **CONFIRMED as a statement about `rx.embed()`'s own return value**, which is
44.6% → 30.3% gate-clean and is what the notebooks inspect.

> the seed was the cleaner geometry

**REFUTED on every axis that has a reference.** Bond lengths improve on 23/23 cases (0.0270 → 0.0179 Å
against real DFT geometry); the seed misses its own angle windows by 6.74° per case and its distance
windows by 0.0735 Å; and on `thia-ma` the seed's conjugation (63.5°) is *worse* than the relaxed 56.4°
against a reference at 16.6°. The seed is cleaner **only** on the conjugation axis, **only** where a C=S
is present, and only relative to a relax that then goes past the truth.

> the test comment's "embed's output is never worse than the seed on any conformer"

**REFUTED as written**, true as scoped to bond tearing (§6.4).

## 9. What could not be established

- **The cause of the `planarity` regression** (15 → 281 violations; `cpa`, `chb-tetramisole`). Localised
  to two cases and shown to be independent of conjugation; not diagnosed further.
- **That UFF's missing C=S torsion barrier is the mechanism.** §6.1 establishes the harm is C=S-localised.
  The force-field explanation is inferred from that localisation; no UFF term was inspected or ablated.
- **Whether a coplanarity cap on C=S would fix it.** Proposed on the strength of the localisation; not
  implemented, not tested.
- **`mc()` and anything downstream of it.** Out of scope, exactly as in the metal study. `mc()` clears
  `_seeds_relaxed` and re-relaxes, so its behaviour does not follow from these numbers. §6.3's chain
  equivalence is `embed → minimize` only; `embed → mc → minimize` was **not** measured.
- **Chain equivalence on `bimp-smiles-auto`.** §6.3 excludes it for runtime, so the chain result rests on
  22 cases / 237 conformers / 3 seeds, not the full 1054. It is the largest single case in §4 and its
  chain behaviour is untested.
- **Absolute correctness of the constraint windows.** For a multi-fragment `.xyz`, §3 shows the auto-added
  encounter window is *not* satisfied by the real geometry (`bimp` (43,151) by 8.97 Å). This study
  measures window *satisfaction*, never window *correctness*, and that is a separate open question.
- **Bond length on SMILES inputs against truth.** Reported against an MMFF94 proxy. The five `.xyz` cases
  carry a real reference and agree in direction, but the SMILES bond-length numbers are proxy-based.
- **Whether the pre-change behaviour was better overall.** §6.3 answers this for the `embed → minimize`
  chain only. Nothing here says the raw-seed `embed()` output was a better *product* — on the window and
  bond-length axes it demonstrably was not.
